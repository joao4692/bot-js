# Pasta de Imagens

Adicione suas imagens nesta pasta para que o comando `/foto` funcione.

## Formatos Aceitos:
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.webp`
- `.bmp`

## Como Usar:
1. Coloque suas imagens nesta pasta
2. Use o comando no Discord: `!foto` (ou conforme configurado)
3. O bot enviará uma imagem aleatória

## Exemplos:
- `meme.png`
- `logo.jpg`
- `gif_animado.gif`
